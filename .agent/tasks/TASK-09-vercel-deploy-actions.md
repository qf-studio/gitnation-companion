### Phase 3: CI workflow

**Goal**: Gate every PR with typecheck, lint, unit tests, e2e, and build.

**Tasks**:
- [ ] Add `.github/workflows/ci.yml`
- [ ] Cache Playwright browsers to avoid the 200 MB download per run
- [ ] Verify the workflow runs green on at least one PR

**Files**:
- `.github/workflows/ci.yml` — PR quality gate

```yaml
name: CI
on:
  pull_request:
    branches: [main]
jobs:
  gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
        with: { version: 9 }
      - uses: actions/setup-node@v4
        with: { node-version: '24', cache: 'pnpm' }
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm test
      - uses: actions/cache@v4
        with: { path: ~/.cache/ms-playwright, key: pw-${{ runner.os }} }
      - run: pnpm exec playwright install chromium --with-deps
      - run: pnpm e2e
      - run: pnpm build
```

### Phase 4: Snapshot refresh workflow

**Goal**: Daily cron that re-pulls upstream `_next/data` JSON and opens a PR when it diverges from the committed snapshot.

**Tasks**:
- [ ] Add `.github/workflows/refresh-snapshot.yml`
- [ ] Ensure the refresh script writes a one-line stats summary to `/tmp/refresh-stats.txt` (follow-up to TASK-02 if missed)
- [ ] Verify `workflow_dispatch` triggers the workflow manually

**Files**:
- `.github/workflows/refresh-snapshot.yml` — daily snapshot refresh + PR
- `/tmp/refresh-stats.txt` — stats summary surfaced in PR body (written by refresh script)

```yaml
name: Refresh snapshot
on:
  schedule:
    - cron: '0 6 * * *'   # 06:00 UTC daily
  workflow_dispatch:
jobs:
  refresh:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
        with: { version: 9 }
      - uses: actions/setup-node@v4
        with: { node-version: '24', cache: 'pnpm' }
      - run: pnpm install --frozen-lockfile
      - run: pnpm refresh:snapshot
      - uses: peter-evans/create-pull-request@v6
        with:
          commit-message: 'chore: snapshot refresh ${{ github.event.schedule || ''manual'' }}'
          title: 'chore: snapshot refresh ${{ format(''YYYY-MM-DD'', github.event.head_commit.timestamp) }}'
          body: |
            Daily snapshot refresh. Review the diff for upstream schema drift.
            Stats:
            ```
            $(cat /tmp/refresh-stats.txt)
            ```
          branch: chore/snapshot-refresh
          delete-branch: true
```

## Out of Scope

- Multi-environment promotion (no staging, just preview + production)
- Edge runtime (Fluid Compute Node 24 LTS is the locked choice)

---

## Technical Decisions

| Decision | Options Considered | Chosen | Reasoning |
|---|---|---|---|
| Config format | `vercel.json`, `vercel.ts` | `vercel.ts` | Per `CLAUDE.md` preference |
| Production promotion | Auto from `main`, manual `vercel promote` | Manual `vercel promote` | Avoid accidental merges hitting prod during demo |
| Refresh wiring | Vercel Cron, GitHub Action + PR | GitHub Action + PR | Snapshot in git → deterministic builds; PR review surfaces schema drift |
| Cron schedule | Hourly, 06:00 UTC daily | 06:00 UTC daily | Off-peak; allows morning review |
| CI Playwright cache | No cache, `actions/cache@v4` | `actions/cache@v4` | Avoid 200 MB browser download per run |
